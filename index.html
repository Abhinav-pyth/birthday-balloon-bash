    How does this work?

    Your message is encrypted with AES‑GCM (256‑bit) using a key derived from your PIN via PBKDF2 (100k iterations), then compressed and stored entirely inside the link itself. There is no server, no database, no tracking. If you lose the PIN, the surprise is unrecoverable — that's real privacy.
